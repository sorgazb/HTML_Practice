> **HTML Practice** es una colección de páginas web estáticas desarrolladas con HTML5 y CSS3, como práctica de la asignatura **Lenguajes de Marca y Sistemas de Gestión de Información** del Grado Superior de DAW — IES Augustóbriga.

---

## 📋 Descripción

Este repositorio contiene cuatro ejercicios prácticos de maquetación web con **HTML5 semántico** y estilos **CSS3**. Los proyectos trabajan con:

- **Etiquetas semánticas** (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) para estructurar el contenido.
- **Formularios HTML5** con validación nativa, tipos de input modernos y atributos de accesibilidad.
- **Tablas y listas** para presentar datos estructurados de forma visual.
- **Estilos CSS3** con selectores, modelo de caja, tipografía y colores.
- **Enlazado de páginas** con navegación entre vistas mediante `<a href>`.

## ⚙️ Uso

Clona el repositorio:
```txt
git clone https://github.com/sorgazb/HTML_Practice.git
cd HTML_Practice
```

### Opción 1 — Live Server (recomendado)

1. Abre la carpeta del ejercicio en **VS Code**.
2. Instala la extensión **Live Server** de Ritwick Dey.
3. Haz clic derecho sobre el `.html` y selecciona **Open with Live Server**.

### Opción 2 — Navegador directamente

```txt
cd DonQuijote
start index.html     # Windows
open index.html      # macOS
xdg-open index.html  # Linux
```
